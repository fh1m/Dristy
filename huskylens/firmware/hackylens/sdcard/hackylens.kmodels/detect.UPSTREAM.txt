The upstream face_detect README states that the KModel was generated by
nncase. It does not identify the training dataset, the original training
repository, or a separate license for the pretrained weights. The repository
README says licenses are specified per demo, but the face_detect directory at
the pinned commit contains no separate license file.

This is the native little-endian KModel v3 consumed by HackyLens. It is not
the 386608-byte, word-swapped/private flash asset extracted from the original
HUSKYLENS firmware package, even though both contain substantially the same
network payload.
